# 支援について

> **翻訳について**: 原文は英語版です。記述が食い違う場合は英語版が優先です。

CPersona は MIT ライセンスです。誰にもお金を払わずに、実行し、読み、変更し、
再配布できます。このページはそれを一切変えません。いまタブを閉じても、
このサイトのほかの記述はすべて、そのままあなたに当てはまります。

支援を受け付けているのは、ライセンスでは賄えない費用があるからです。時間と、テスト
スイートを走らせるマシンと、いま読んでいるページを書く時間です。

CPersona があなたのワークフローで役に立ち、それが続いてほしいと思っていただけた
なら、[GitHub Sponsors で Cloto-dev を支援](https://github.com/sponsors/Cloto-dev)
できます。単発でも月額でも同じように歓迎します。どちらも必須ではありません。

## 支援で得られないもの { #what-sponsorship-does-not-buy }

逆の取り決めの方が世の中では珍しくないので、はっきり書いておきます。

- **支援者向けに機能を出し惜しみしません**。有料ティアも、支援者限定ビルドも、
  それを作る計画もありません。
- **issue の順番は上がりません**。issue は影響度・再現性・安全性で判断します。
  一度も支援したことがない人からの再現可能なデータ損失の報告は、誰からの機能要望
  よりも優先されます。
- **サポート契約ではありません**。応答時間の約束は付いておらず、付いている前提で
  予算を立てるべきではありません。

支援ページは 1 つで、CPersona と [ClotoCore](https://github.com/Cloto-dev/ClotoCore)、
同じアカウントで公開しているほかのプロジェクトをまとめて受けています。
そのため「CPersona だけに」と指定することはできません。これは支援の受け方の制約で、
隠さずにそのまま書いています。

## 使い道 { #where-it-goes }

開発の時間、検証とインフラ (埋め込みのベンチマークを走らせるマシンを含む)、
ドキュメントの整備、リリース済みの系列の保守、質問への回答に使います。

## お金がかからない助け方 { #ways-to-help-that-cost-nothing }

この規模のプロジェクトでは、こちらのほうが金銭より価値があります。このページで後ろに
置いたのは、説明に行数がかかるからにすぎません。

- **リポジトリに Star を付ける**。CPersona を必要としている次の人が見つけられるかを
  左右する、いちばん手間のかからない目印です。
- **セットアップのどこで詰まったかを教える**。設定の問題をバグと取り違えたなら、
  ドキュメントが分かりにくかったということで、それ自体が不具合です。何も壊れて
  いなくても、その報告は歓迎です。
- **再現手順つきで issue を立てる**。修正の速さを最も左右するのは再現性です。
- **ドキュメントの 1 文を直す**。あるいは「あってほしかった例」を足す。
- **CPersona が解く問題を抱えている人に伝える**。CPersona を使っている人の多くは、
  検索ではなく人づてに知っています。

## 公開でのお礼 { #being-thanked-in-public }

支援者は既定ではどこにも掲載しません。公開でお礼を言われたい場合は、そう伝えて
ください。表記名とリンクをご希望どおりに書いて掲載します。何も言わなければ、何も
公開しません。

なお、GitHub 自体の支援者一覧には表示されます。そちらで非公開にできますが、それは
このプロジェクトではなくあなた側の設定です。
