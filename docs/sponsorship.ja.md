# 支援について

> **翻訳について**: 正本は英語版です。記述が食い違う場合は英語版が優先です。

CPersona は MIT ライセンスです。誰にお金を払わなくても、実行でき、読め、変更でき、
再配布できます。このページはそれを一切変えません。いまタブを閉じても、
このサイトの他のすべてはあなたに完全に当てはまります。

支援の仕組みがあるのは、ライセンスが賄わない費用があるからです。時間、テスト
スイートを走らせるマシン、そしていま読んでいるページを書く時間です。

CPersona があなたのワークフローで役に立ち、それが続いてほしいと思っていただけた
なら、[GitHub Sponsors で Cloto-dev を支援](https://github.com/sponsors/Cloto-dev)
できます。単発・月額のどちらも同じように歓迎で、どちらも必須ではありません。

## 支援が買わないもの { #what-sponsorship-does-not-buy }

逆の取り決めの方が世の中では珍しくないので、はっきり書いておきます。

- **支援者向けに機能を出し惜しみしません。** 有料ティアも、支援者限定ビルドも、
  それを作る計画もありません。
- **issue の順番は上がりません。** issue は影響度・再現性・安全性で判断します。
  一度も支援したことがない人からの再現可能なデータ損失の報告は、誰からの機能要望
  よりも優先されます。
- **サポート契約ではありません。** 応答時間の約束は付いておらず、付いているものと
  して予算を立てるべきではありません。

支援ページは CPersona と [ClotoCore](https://github.com/Cloto-dev/ClotoCore)、
および同じアカウントで公開している他のプロジェクトをまとめて 1 つで受けています。
そのため「CPersona だけに」と指定することはできません。これは仕組みの制約であり、
ごまかさずにそのまま書いています。

## 使い道 { #where-it-goes }

開発時間、検証とインフラ (埋め込みのベンチマークを走らせるマシンを含む)、
ドキュメント整備、リリース済みラインの保守、そして質問への回答です。

## お金がかからない助け方 { #ways-to-help-that-cost-nothing }

この規模のプロジェクトでは、こちらの方が金銭より価値があります。後に並んでいるのは、
説明に行数がかかるからにすぎません。

- **リポジトリに Star を付ける。** これを必要としている次の人が見つけられるかを
  左右する、いちばん安い信号です。
- **セットアップのどこで詰まったかを教える。** 設定の問題をバグと取り違えたなら、
  それはドキュメントが不明瞭だったということで、それ自体が不具合です。何も壊れて
  いなくても、その報告は歓迎です。
- **再現手順つきで issue を立てる。** 修正の速さを最も変えるのは、再現性です。
- **ドキュメントの 1 文を直す。** あるいは「あってほしかった例」を足す。
- **これが解く問題を抱えている人に伝える。** CPersona を使っている人の多くは、
  検索ではなく人づてに知っています。

## 公開でのお礼について { #being-thanked-in-public }

支援者は既定ではどこにも掲載しません。公開でお礼を言われたい場合は、そう伝えて
ください。表記名とリンクをご希望どおりに書いて掲載します。何も言わなければ、何も
公開しません。

なお GitHub 自身の支援者一覧には表示されます。そちらで非公開にできますが、それは
このプロジェクトではなく、あなた側の設定です。
